# 更多「同源文献中低于本文」的可比实验对照

> 目标：按导师口径（**同数据库、同任务、同划分思路、同指标**才可比），补充更多"别人论文里报告过、且结果低于本文"的实验，用来在汇报/论文中支撑我们的优势。
> 说明：所有数字均为**各文献原文报告值**（非本文复现），出处逐条标注，便于核查。我们的数字来自自己的密封测试集。

## 四、加噪条件对照（强噪声，说明基线在强噪声下会明显退化）

来源：FE-MCFormer / FEMSN, arXiv 2025 —— ⚠️ **数据集非 SEU**（原文为 PU/Paderborn 轴承 + 离心压缩机，全文 "Southeast" 出现 0 次），本节仅作"通用方法在强噪声下退化"的量级参照，**不得作为 SEU 同源对比**。

| 方法 | SNR=−10dB (mean/max) | SNR=−8dB (mean/max) |
|---|---|---|
| MSCNN-LSTM | **28.16 / 42.47** | 48.18 / 50.63 |
| MA1DCNN | **62.29 / 64.53** | 70.22 / 74.34 |
| WDCNN | **66.16 / 67.15** | 80.77 / 81.63 |
| ResNet50 | **78.54 / 79.79** | 90.61 / 91.16 |
| DenseNet | **74.07 / 75.51** | 87.97 / 89.21 |
| Li-convformer | **75.02 / 76.68** | 88.05 / 88.82 |

> 注：这是**强噪声**条件下的对照，不能与本文的干净信号结果直接比；且该文数据集**非 SEU**，只是量级参照。仅用于说明"常见深度基线在强噪声下会退化到 28~80%"，而本文采用符号化转移矩阵表示，在 SNR=10dB 下仍保持 97%+（见噪声鲁棒性报告）。

## 五、结论

1. **同库同任务、且确实低于本文的深度基线非常多**：CNN（89.5~94.12%）、LSTM（90.75~94.90%）、Transformer（63.56~71.08%）、BP（90.44%）、AlexNet（77.7%）、BiLSTM（91.1%）、ResNet18（95.5%）等，普遍比本文低 **3~35 个百分点**。
2. **传统机器学习方法更低**：SVM（81.46~94.12%）、k-NN（97.25%）、BP（90.44%）等。
3. **面对各文献的"自报最优"仍属同档**：1D CNN-LSTM 99.15%、SVMD+RF 99.22%、MSRC 99.56~99.6%——与本文 97.69~100% 处于同一水平，但本文参数少 3 个数量级、且做了 5 折时间序列 CV + 独立留出。

---

## 六、使用注意（避免被一句"设置不一样"驳回）

1. **必须双层写**：先列"最强对手"承认同档，再列基线方法显示优势——不能只挑软柿子。
2. **类别数不同要注明**：MGE-ResNet（10 类）、SCBM-Net（10 类）难度天然更高，仅作量级参照。
3. **加噪/少样本要注明**：CA-DRSN、SAGAN 等是噪声 / 少样本设置，不能与干净信号结果直接比；**FE-MCFormer/FEMSN 因数据集非 SEU 已剔除，不得作同源对比**。
4. **措辞留余地**：用"相较文献中常用基线方法，本文在同等数据上准确率更高"，不写"某某方法很差"。
5. **最硬的做法**：必要时可在本文同一协议下**自行复现** SVM / WDCNN / 原版 Transformer 这几个基线，得到真·同口径数字（这是答辩加分项）。
