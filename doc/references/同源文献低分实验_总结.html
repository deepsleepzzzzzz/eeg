效率部分的诚实边界

  1. FLOPs 与输入模态强相关：本文输入是 21×6×6 符号矩阵，文献多用 1024/2048/4096 点原始信号或 224×224 图像，口径不完全相同。故只主张"各自报告口径下本模型最轻"，不夸大为"快几千倍"。
  2. 硬件不同：本文延迟/吞吐在 RTX 4060（batch=32）测得，文献硬件未知，跨论文绝对延迟仅作量级参照。
  3. 最稳的三项：参数量、模型大小、同硬件延迟（与输入模态无关或弱相关），是最可靠的效率优势。
  4. 有一个真劲敌：ADGCC-Net（Processes 2025）模型 0.082 MB，与本文 104 KB 同量级——"轻量"赛道并非无人，但其准确率/任务覆盖不及本文。

四、四个层面结论

  1. 常见深度基线明显低于本文：CNN（89.5~94.1%）、LSTM（90.8~94.9%）、Transformer（63.6~71.1%）、BP（90.4%）、AlexNet（77.7%）、BiLSTM（91.1%）、ResNet18（95.5%）——低 3~35 个点。
  2. 传统机器学习方法更低：SVM（81.46~94.12%）、k-NN（97.25%）、BP（90.44%）。
  3. 面对"自报最优"仍属同档：1D CNN-LSTM 99.15%、SVMD+RF 99.22%、MSRC 99.56~99.6%，与本文 97.69~100% 同一水平——但本文参数少约 3 个数量级，且是唯一同时做 5 折时间序列 CV + 独立留出的。
  4. 速度/效率优势最硬：CNN 仅 2.5 万参数 / 104 KB / 0.384 MFLOPs，单样本 0.02~0.03 ms，吞吐 3.7 万~5.3 万样本/秒；相比同源文献参数少 8~366 倍、算量少 26~5000 倍、体积小 60 倍以上。

使用注意（避免被一句"设置不一样"驳回）

  1. 双层写：先列"最强对手"承认同档，再列基线方法显优势，不能只挑软柿子。
  2. 类别数不同要注明：MGE-ResNet、SCBM-Net 是 10 类，难度天然更高，仅作量级参照。
  3. 加噪/少样本要注明：CA-DRSN、FEMSN、SAGAN 是噪声或少样本设置，不与干净信号结果直接比。
  4. 措辞留余地：写"相较文献中常用基线方法，本文在同等数据上准确率更高"，别写"某某方法很差"。
  5. 最硬的做法：必要时在本文同一协议下自行复现 SVM / WDCNN / 原版 Transformer 基线，得到真·同口径数字（答辩加分项）。

五、给导师的一句话汇报（口语版）

"准确率上，我在同一个 SEU 数据库上跟常见方法比，普遍高三到三十五个点，跟各篇里最好的那个数是一个水平。更硬的是'快'：我的模型只有 2.5 万个参数、104 KB、0.38 MFLOPs，一个样本 0.02 毫秒出结果，一秒能算 3.7 万到 5.3 万个样本；跟同源文献比，参数少 8 到 366 倍、算量少 26 到 5000 倍、体积小 60 倍以上。别人还要预处理加降噪，我这边符号矩阵直接进网络。所以'轻量、实时、省电'这条线，是明显站得住的。"
