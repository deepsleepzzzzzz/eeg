## 30 秒版

我们做的是：同一个人自己的脑电，四类 Go/Nogo 任务，刺激后 800 毫秒。

做法是：先把信号切成 6 个幅值状态，数 1、2、3 步怎么跳，做成转移矩阵；再用 CNN 或 GCN 分类。

规矩是：测试集不参与训练，也不参与选参数。

结论是：同一套「训练集定边界」的矩阵上，GCN 开图注意力最好；CNN 再扫学习率收益很小。它的点估计仍低于「每个试次自己定边界」的堆叠 CNN，也低于已冻结的 RP；但和前者的差距不能说成「显著更高」。

## 方法

| 他们问 | 你答 | 别说 |
|---|---|---|
| 状态转移是什么？ | 幅值切成 6 档，看状态怎么跳；31 个导联叠在一起，输入形状是 93×6×6。 | 和 RP 图像混成一种方法 |
| 「统一节点编号」是什么？ | 边界只由这个人的训练集幅值定出来，验证集和测试集共用。像尺子只在训练集上刻好。 | 「边界用了测试集」 |
| 和「按试次分档」差在哪？ | 按试次：每个试次自己刻尺子。统一节点：尺子来自训练集。后者更干净、可复现；点估计可能低一些。 | 把两套表示的数字当成同一种实验 |
| CNN 和 GCN 啥关系？ | 二选一的骨干，不叠在同一个模型里。注意力是开关，不是第三种骨干。 | 「GCN 是在 CNN 上面再加一层」 |
| 为什么两个分支？ | `master` 是 CNN；`feat/transition-gcn` 是 GCN。主干只收了对照文档，没收 GCN 代码。 | 「仓库里现在只有一套模型」 |
| 自注意力加在哪？ | 加在卷积前。池化后图会缩成 1×1，放后面等于白做。 | 「和 SE 装在同一位置」 |
| 图注意力是什么？ | 在图的边上决定消息该听谁：既看节点特征，也看转移概率。 | 和 CNN 的自注意力当成同一个模块 |

## 「你们有没有作弊？」这类

| 他们问 | 你答 | 别说 |
|---|---|---|
| 测试集进训练了吗？ | 没有。训练默认不读测试集；GCN 和优化后 CNN 的记录都写着测试未评。 | 「训练时顺便看了测试分」 |
| 测试分怎么来的？ | 验证集定方案后，用存好的最佳权重评一次测试集，没有重训。 | 「用带测试开关的训练命令又训了一遍」 |
| 调参偷看测试了吗？ | 没有。CNN 在少数人的验证集上选学习率等；GCN 没扫学习率。选的时候不用测试标签。 | 「按测试准确率选模型」 |
| 划分后来改过吗？ | 没有。指纹对得上。例如 sub-002 仍是 1708 / 366 / 366。 | 「为了提分重划过」 |
| 对照公平吗？ | 统一节点这一套里，CNN 和 GCN 吃同一份矩阵。 | 拿「按试次分档」的结果冒充同一表示上的对比 |
| 别人怎么验？ | 用冻结划分、矩阵缓存、权重和每人的预测表，可以自己重算准确率。 | 只甩一张总表让人「相信平均数」 |

## 被追问时三句短答

**有没有数据泄漏？**  
没有。划分冻住；尺子只在训练集上刻；训练不读测试；调参只看验证；测试用存好的权重评一次。

**为什么有个 CNN 看起来更高？**  
那是另一套「按试次分档」表示。点估计高 0.0168，但配对比区间含 0，不能叫显著更高。统一节点这一套内部，GCN 更高。

**最终结论一句？**  
统一节点、按导堆叠的转移矩阵上，GCN 加图注意力是当前最好的骨干；图注意力开对比关有效；CNN 再扫学习率收益很小；整体点估计仍低于冻结 RP，且我们不声称显著超过按试次分档的堆叠 CNN。

## 给你自己的查表顺序

1. 先分清对方问的是规矩、方法，还是分数。  
2. 分数只念表里的，不要现场四舍五入编新数。  
3. 问到「显不显著」：有区间就报区间；含 0 就明确说不能叫显著。  
4. 问到「能不能复现」：说划分文件、矩阵、权重、预测表都能重算。  
5. 拿不准就说「以仓库里的 results / method 为准」，不要现场发明。
